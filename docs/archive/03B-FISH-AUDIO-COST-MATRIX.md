## Character Calculation Methodology

### Base Assumptions

| Parameter | Value | Source |
|-----------|-------|--------|
| **Narration speed** | 150 words/minute | Standard for educational content |
| **Characters per word** | 6.5 | English language average |
| **Fish Audio API pricing** | $15 per 1M characters | Official API pricing (2026) |

### Formula

```
Characters = (Duration in seconds ÷ 60) × 150 words/min × 6.5 chars/word
```

## Cost Optimization Strategies

### Strategy 1: Start Small, Scale Fast
- **Month 1-3:** 5 channels (test quality, refine workflows)
- **Month 4-6:** Scale to 10 channels (proven model)
- **Month 7+:** Scale to 15-20 channels (revenue-funded)
- **Savings:** Lower initial risk, validate before scaling

### Strategy 2: Optimize Video Length by Performance
- **Month 1-2:** Test 8, 9, 10-minute versions per niche
- **Month 3+:** Use best-performing length per channel
- **Savings:** 8-min videos cost 11% less than 10-min, if retention is equal

### Strategy 3: Dynamic Short Duration
- **High-performing channels:** 60-sec shorts (more value)
- **New channels:** 30-sec shorts (lower cost, test hooks)
- **Savings:** Up to 50% on short-form voice costs

### Strategy 4: Batch Voice Generation
- Generate all scripts for the week in one API call
- Reduces API overhead and request latency
- **Savings:** Minimal, but improves workflow efficiency
