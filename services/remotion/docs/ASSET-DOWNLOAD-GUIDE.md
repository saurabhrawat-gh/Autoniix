## Step 6: After Downloads — Run Integration

Once all assets are downloaded, the codebase integration will:

1. **Auto-scan** `/public/assets/` directories
2. **Register** all assets in their respective library registries
3. **Generate** preset IDs automatically (e.g., `grain.envato.35mm_fine_01`)
4. **Set** quality ratings and default parameters
5. **Make available** in Direction Format JSON

The following code files handle this:
- `src/registry/grainLibrary.ts` — Film grain presets
- `src/registry/lutLibrary.ts` — LUT presets
- `src/registry/overlayLibrary.ts` — Visual overlay presets
- `src/registry/sfxLibrary.ts` — SFX presets (expanded)
- `src/services/assetResolver.ts` — Premium-first resolution
